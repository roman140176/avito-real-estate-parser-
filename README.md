# Avito Real Estate Parser

Локальный инструмент для выгрузки объявлений о продаже и аренде квартир и домов с Авито. Он открывает обычные страницы поиска в Chromium через Puppeteer, показывает результаты в браузере и позволяет скачать их в JSON, CSV или XLS.

Проект рассчитан на запуск на собственном компьютере. Это не SaaS и не сервис для массового сбора данных.

## Возможности

- Поиск по городу, типу сделки и недвижимости.
- Выбор диапазона страниц с ограничением на один запуск.
- Локальные фильтры по цене, площади и числу комнат.
- Извлечение площади, комнат, материала стен и года постройки, если они указаны в карточке.
- Фильтры результатов по району, продавцу и материалу стен.
- Экспорт в JSON, CSV и XLS.
- Ручное прохождение CAPTCHA в видимом окне Chromium по желанию пользователя.

## Требования

- Node.js 20.18 или новее.
- Интернет-соединение.
- Chromium, который Puppeteer загрузит автоматически при обычном `npm install`.

## Установка и запуск

```bash
git clone <repository-url>
cd avito-real-estate-parser
npm install
cp .env.example .env
npm start
```

Откройте [http://localhost:3000](http://localhost:3000). Выберите параметры и нажмите «Начать парсинг».

Для ручного прохождения CAPTCHA используйте чекбокс в интерфейсе или запустите:

```bash
npm run start:captcha
```

Не пытайтесь обходить ограничение доступа: если сайт ограничил запросы, остановите запуск и проверьте применимые правила доступа.

## Настройки

Значения задаются в `.env`; файл создаётся из `.env.example` и никогда не должен попадать в Git.

| Переменная | По умолчанию | Назначение |
| --- | --- | --- |
| `PORT` | `3000` | Локальный порт приложения |
| `HEADLESS` | `true` | Запуск Chromium без окна |
| `ALLOW_MANUAL_CAPTCHA` | `false` | Разрешить ручной CAPTCHA-режим |
| `CAPTCHA_WAIT_MS` | `180000` | Время ожидания ручного подтверждения |
| `DATA_DIR` | `./data` | Локальная папка выгрузок |
| `BROWSER_PROFILE_DIR` | `./.local/browser-profile` | Локальная сессия Chromium |
| `DEFAULT_PAGES` | `1` | Страниц по умолчанию |
| `MAX_PAGES` | `10` | Максимум страниц за запуск |
| `PAGE_FETCH_RETRIES` | `3` | Повторы пустой страницы |
| `AVITO_PROXY_*` | пусто | Необязательные параметры корпоративного прокси |

`PUPPETEER_NO_SANDBOX=true` используйте только в изолированной среде, где Chromium иначе не запускается. В обычной локальной установке он не нужен.

## Данные

После запуска результат хранится локально в `data/avito_data.json`. Новый запуск заменяет предыдущую выборку. Каждая запись может содержать:

```json
{
  "id": "…",
  "title": "…",
  "price": "…",
  "priceValue": 0,
  "area": 0,
  "rooms": 0,
  "wallMaterial": "…",
  "buildYear": 0,
  "location": "…",
  "realtorName": "…",
  "url": "…",
  "sourceUrl": "…",
  "sourcePage": 1
}
```

Поля, которые не удалось уверенно извлечь, имеют значение `null` или пустую строку. Всегда сверяйте важные параметры с исходным объявлением.

## Разработка

```bash
npm test
npm run check
npm run audit:prod
```

Тесты используют только синтетические данные; реальные объявления, адреса, профили браузера, cookies и прокси-учётные данные в репозитории отсутствуют.

## Публикация и ответственное использование

`.gitignore` исключает `.env`, `node_modules`, `.local/` и содержимое `data/`. Не добавляйте их принудительно: профиль браузера может содержать cookies и историю, а выгрузки — адреса и другие данные из объявлений.

Перед использованием проверьте актуальные [Условия использования Авито](https://www.avito.ru/legal/rules/terms-of-use) и [robots.txt](https://www.avito.ru/robots.txt). Соблюдайте применимые правила, права третьих лиц и требования к обработке данных.
